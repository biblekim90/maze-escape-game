# 🧩 미로찾기 - 30초 탈출

방향키로 미로를 탐험해 30초 안에 초록색 도착점까지 탈출하는 웹 게임입니다.

## 🎮 플레이

👉 [지금 플레이하기](https://biblekim90.github.io/maze-escape-game/maze.html)

## 조작법

- **PC**: 방향키 (↑ ↓ ← →), **R**로 재시작
- **모바일**: 화면의 방향키 버튼 또는 미로 위에서 스와이프로 이동

## 기능

- **난이도 3단계**
  - 하 (9×9)
  - 중 (13×13)
  - 상 (17×17)
- **30초 카운트다운**: 남은 시간에 따라 초록 → 노랑 → 빨강으로 변하는 타이머 바
- **매판 새로운 미로**: 재귀적 백트래킹(recursive backtracking) 알고리즘으로 자동 생성
- **모바일 최적화**: 반응형 레이아웃 + 가상 방향키 + 스와이프 조작
- **카카오톡/SNS 공유 썸네일**: Open Graph 메타 태그로 링크 공유 시 미리보기 이미지 노출

## 기술 스택

- HTML / CSS / Vanilla JavaScript
- `<canvas>` 2D 렌더링

## 로컬 실행

`maze.html` 파일을 브라우저로 열면 바로 실행됩니다.
